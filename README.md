# HR Data Cleaning and Analysis

## Project Overview
This project analyzes an HR dataset using Python, Pandas, and Matplotlib. The aim is to clean employee data, create pivot tables, visualize important metrics, and identify useful insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- CSV Dataset
- Visual Studio Code

## Data Cleaning
- Removed duplicate records.
- Removed extra spaces from text columns.
- Checked missing values.
- Saved the cleaned dataset as `HR_Dataset_Cleaned.csv`.

## Pivot Tables
1. Average salary by department.
2. Employee count by gender.
3. Average training cost by training type.

## Visualizations
The project includes charts for:
- Average salary by department.
- Average training cost by training type.
- Employees by gender and department.

## Key Insights
1. The dataset contains 3,000 employee records after cleaning.
2. There are 1,682 female employees and 1,318 male employees.
3. Average external training cost is approximately 556.82.
4. Average internal training cost is approximately 560.42.
5. The average training costs for internal and external training are quite similar.

## Conclusion
This project demonstrates basic data cleaning, pivot table analysis, and data visualization. These techniques help summarize HR data and identify useful patterns.
