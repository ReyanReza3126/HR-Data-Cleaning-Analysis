# HR Data Cleaning and Analysis

## Project Overview
This project analyzes a messy HR dataset using Python and Pandas. The objective is to clean the data, create pivot tables, visualize employee information, and identify useful insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- CSV Dataset

## Data Cleaning
- Removed duplicate records.
- Removed extra spaces from text columns.
- Checked missing values.
- Saved the cleaned dataset as `HR_Dataset_Cleaned.csv`.

## Pivot Tables
1. Employees by Department
2. Employees by Gender
3. Average Training Cost by Training Type

## Visualizations
Three charts were created:
- Employees by Gender
- Employees by Department
- Average Training Cost by Type

## Key Insights
- The dataset contains 3,000 employee records after cleaning.
- Female employees: 1,682.
- Male employees: 1,318.
- Average external training cost: approximately 556.82.
- Average internal training cost: approximately 560.42.

## Conclusion
The analysis summarizes employee distribution and training costs. Pivot tables and charts make the HR data easier to understand.
